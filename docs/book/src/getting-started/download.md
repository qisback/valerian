# Get Valerian

Valerian is free software under the GPLv3, and its complete source is public on
[GitHub](https://github.com/qisback/valerian). There are two ways to get it.

## Installers from 12hobbies.studio

Ready-made installers for Windows, Debian and Ubuntu, Fedora and other Linux systems are sold on
[12hobbies.studio](https://12hobbies.studio/projects/valerian/). **That page is coming soon** while the
store is set up. Buying an installer supports Valerian's development. Every version comes with a
`SHA256SUMS` file; [Getting started](install.md) shows how to check it.

## Build it from source

Building from source is supported on every system Valerian runs on, and gives you the same programs.
[Build from source](build-from-source.md) has the steps for Windows, macOS, Debian, Ubuntu, Raspberry Pi,
Fedora, Arch and other Linux systems, how to check the result, and what to do when a build fails.

Once Valerian is installed, [Getting started](install.md) has more detail.
